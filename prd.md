Project Title: An Integrated Explainable AI (XAI) Framework for Early Risk Assessment of Lifestyle-Induced Non-Communicable Diseases via Multimodal Data Fusion.

1. Executive Summary
XAI-CDSS is a Trustworthy AI framework designed for preventive healthcare decision support. Unlike reactive clinical models, this system provides early risk assessment for chronic diseases by fusing behavioral lifestyle data with clinical indicators. It addresses the "black-box" nature of traditional ML by providing interactive, mathematical explanations (SHAP) interpreted into natural language via Large Language Models (Google Gemini).

2. Research Problem & Objectives
Problem: Current healthcare is reactive; ML models often lack transparency (black-box), leading to low clinician trust and limited preventive utility.

Core Objective: Build a unified, scalable architecture that performs simultaneous risk assessment for multiple interconnected diseases (Diabetes, Heart Disease, Stroke) while providing actionable clinical rationale.

SDG Alignment: Goal 3 — Good Health and Well-being.

3. Target User Personas
Clinicians/Physicians: Use the dashboard as a clinical decision support tool to validate risk levels and provide patients with evidence-based lifestyle advice.

Health-Conscious Individuals: Self-assess risk based on daily habits and demographics to take preemptive action.

Medical Panels (Reviewers): Technical and clinical experts evaluating the mathematical consistency and explainability of the AI framework.

4. Product Novelty Pillars
Multimodal Data Fusion: Fuses clinical markers (e.g., BMI, BP) with behavioral/lifestyle factors (e.g., physical activity, smoking, alcohol) and demographics.

LLM-Augmented Explainability: Uses a strictly grounded prompt to convert raw SHAP influence percentages into panel-friendly clinical reports via Gemini AI.

Unified Multi-Disease Vector: A single patient input vector drives three parallel diagnostic ensembles (Diabetes, Heart, Stroke).

5. Technical Specifications
5.1 Machine Learning Stack
Base Estimators: Logistic Regression, Random Forest, XGBoost.

Ensemble Method: Weighted Soft Voting Ensemble.

Data Pre-processing: * Imbalance handling via SMOTE (Synthetic Minority Over-sampling Technique).

Standardization via StandardScaler.

Explainability: SHAP (Shapley Additive Explanations) TreeExplainer for XGBoost sub-estimators.

5.2 Software Architecture
Backend: FastAPI (Python) serving as a RESTful gateway.

Frontend: Next.js (TypeScript), Tailwind CSS, Recharts for analytical visualization.

LLM Integration: Direct REST API integration with Google Gemini (Model chain: gemini-2.0-flash -> 1.5-flash).

Modular Design: Separates Inference Engine, XAI Module, and Interpretation Fallback.

6. Functional Requirements
6.1 Patient Assessment Module
Handle 22 multimodal features (e.g., HighBP, HighChol, BMI, Smoker, Fruits, Veggies, HvyAlcoholConsump, GenHlth, etc.).

Group inputs logically into Demographic, Lifestyle, and Clinical categories.

6.2 Analytical Dashboard
Unified Inference: Simultaneous risk gauge generation for Diabetes, Heart Disease, and Stroke.

Interactive XAI Plots: Horizontal bar charts displaying feature influence (Risk vs. Protective).

Clinical Synthesis: Professional-grade medical report generated by Gemini based on SHAP values.

System Resilience: Local heuristic fallback interpretation if LLM API is unavailable.
